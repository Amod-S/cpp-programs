# C++ Programs: Basics, OOP and DSA

My C++ practice repository. I'm a 2nd-year computer engineering student, and I use this repo to practice programming fundamentals, object-oriented programming, and data structures & algorithms. The way I practice is by taking on small tasks with clear outputs/ goals and by tackling 1 data structure or 1-2 oop concepts at a time. Currently I am not using STL so that I can build my coding intuition and skills. I will use them later, to take on harder tasks.

## Structure

| Folder | What's inside |
|--------|---------------|
| `basics/` | Beginner programs: input/output, conditions, loops |
| `dsa/` | Data structures and algorithms practice |
| `oop/` | Object-oriented programming assignments |

## Programs

### basics
- `calculator.cpp`: simple calculator
- `intro.cpp`: first program
- `pythagorus.cpp`: Pythagorean theorem calculator
- `randomm.cpp`: random number generation
- `rock_paper_scissors.cpp`: rock paper scissors game
- `temperature_conversion.cpp`: temperature unit converter
- `tictactoe.cpp`: tic-tac-toe game

### dsa
- `bubble_sort.cpp`, `insertion_sort.cpp`: sorting algorithms
- `simple_queue.cpp`, `circular_queue.cpp`, `priority_queue.cpp`: queue implementations
- `parenthesis_checker.cpp`: balanced parentheses checker
- `rainfall_tracking.cpp`: 2*2 array

### oop
- `assmt1.cpp`: basic class and object creaion, methods
- `oop_assmt2.cpp`: use of constructors and validation in methods

## How to run

Make sure you have a C++ compiler (g++) installed, then:

```
g++ filename.cpp -o filename
./filename
```

On Windows, run `filename.exe` instead of `./filename`.
